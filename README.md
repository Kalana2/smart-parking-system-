# Smart Parking System

An AI-powered Smart Parking System designed to detect, monitor, and manage parking slot availability in real time using Computer Vision and modern web technologies.

The system uses live camera feeds and vehicle detection models to identify occupied and vacant parking spaces, helping reduce traffic congestion, parking search time, and manual parking management issues.

## Features

* Real-time vehicle detection
* Parking slot occupancy monitoring
* Live dashboard for slot availability
* Vehicle tracking and monitoring
* REST API backend services
* Scalable microservice-based architecture
* Database integration for parking data management
* Future support for ANPR and reservation systems

## Technologies Used

* YOLO
* Flask / FastAPI
* React.js
